# 감사원 정보시스템 감사보고서 분석 — 13건

`정보시스템_관련/1_높음_제목일치/`의 보고서 13건(감사사항 제목에 정보화·정보시스템 키워드가 직접 포함된 최고 관련도 자료)을 전문(全文) 정독하여 각각 분석한 자료다.

## 문서 구성

모든 분석은 동일한 5장 구조를 따른다.

| 장 | 내용 |
|---|---|
| **1. 종합적인 시사점** | 정보시스템 감리인 관점에서 이 감사가 말하는 것 |
| **2. 감사개요** | 감사 배경·목적, 중점, 대상, 방법(감사원이 쓴 검증 기법 포함) |
| **3. 처분요구사항** | 지적사항별 처분 종류·대상·**처분 근거 법령**, 처분요구 원문, 인용 법령 요지 |
| **4. 피감사인이 준수했어야 하나 준수하지 못한 사항** | 준수 규범 / 요구되었던 행위 / 실제 행위 / 결과 |
| **5. 감사교훈으로 도출한 정보시스템 감리인 점검항목** | 점검항목 / 확인 방법·증빙 / 근거 사례 + "즉시 물어야 할 질문" |
